# MyApp - 宝宝记录

Jetpack Compose + Material 3 构建的宝宝成长记录 Android 应用。

## 技术栈

- **UI**: Jetpack Compose + Material 3
- **导航**: Navigation Compose
- **分页**: Paging 3
- **图表**: Vico Chart
- **存储**: DataStore
- **网络**: Retrofit 2.9.0 + OkHttp 4.12.0
- **图片**: Coil 2.6.0
- **数据库**: Room 2.6.1 + KSP
- **异步**: Kotlin 协程 + Flow
- **DI**: Koin 3.5.6
- **架构**: MVVM（ViewModel + StateFlow）
- **构建**: Gradle 9.5.1 + AGP 8.9.3
- **语言**: Kotlin 1.9.22, Java 17
- **compileSdk / targetSdk**: 34, **minSdk**: 24

## 编译

```bash
sh build.sh            # debug
sh build.sh assembleRelease  # release
```
