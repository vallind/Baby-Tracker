# UI 设计稿与页面布局说明

## 1. 全局布局规范

| 属性 | 值 |
|------|-----|
| 页面边距 | 16dp |
| 卡片间距 | 12dp |
| 圆角 | 24dp |

## 3. 状态模式

每个列表页面的状态流转：

```
Loading (CircularProgressIndicator)
    ↓
Empty (EmptyState: 图标 + 文案)
    ↓
Success (LazyColumn + ParentingCard)
    ↓
Error (ErrorView: 错误信息 + 重试按钮)
```
