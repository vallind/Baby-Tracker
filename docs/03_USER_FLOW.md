# 用户流程与关键场景

## 1. 首次使用流程

```
启动 App → 创建宝宝信息（姓名/性别/生日/出生数据）
         → 进入首页
         → 开始记录喂养/睡眠/生长数据
```

## 2. 日常使用流程

### 记录喂养

```
首页 → 点击"喂养" → 喂养记录列表
         → 点击 FAB(+) → 选择类型 → 输入用量
         → 可选备注 → 保存 → 返回列表
```

### 记录睡眠

```
首页 → 点击"睡眠" → 睡眠记录列表
         → 点击 FAB(+) → 选择类型(夜间/小睡)
         → 设置开始/结束时间 → 保存
```

### 记录生长

```
首页 → 点击"生长" → 生长记录列表 + 趋势图
         → 点击 FAB(+) → 输入身高/体重/头围
         → 保存 → 图表自动更新
```

### 管理疫苗

```
首页 → 点击"疫苗" → 疫苗列表（状态标记）
         → 点击 FAB(+) → 输入名称/针次/计划日期
         → 保存 → 可标记"已完成"
```

### 查看统计

```
首页 → 点击"统计" → 喂养次数/睡眠时长/身高趋势
         → 数据自动汇总
```

### 查看健康档案

```
首页 → 点击"健康" → 编辑过敏史/病史/医生备注 → 保存
```

## 3. 关键场景

### 场景一：妈妈记录晨间喂养

1. 打开 App → 首页
2. 点击"喂养记录"
3. 点击 + 号
4. 选择"母乳"
5. 输入用量 (120ml)
6. 点击保存
7. 自动返回列表，首页今日概览更新

### 场景二：爸爸记录宝宝午睡

1. 打开 App → 首页
2. 点击"睡眠记录"
3. 点击 + 号
4. 选择"白天小睡"
5. 确认开始时间 (13:00)，设置结束时间 (14:30)
6. 点击保存

### 场景三：查看生长趋势

1. 打开 App → 首页
2. 点击"生长记录"
3. 切换 Tab 查看身高/体重/头围折线图
4. 新增测量数据 → 图表自动更新
