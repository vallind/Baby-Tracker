# Baby Tracker「AI 育儿助手」文档索引

> 更新日期：2026-07-22

AI 育儿助手是 Baby Tracker 现有应用中的一个功能模块。为避免把本次开发范围与长期设想混在一起，需求文档拆分为两份：

1. [AI育儿助手总体规划](AI育儿助手总体规划.md)
   - 定义功能最终形态、能力地图、版本路线和长期技术演进。
   - 用于判断方向，不作为某个版本直接开工的唯一依据。

2. [AI育儿助手V1功能PRD](AI育儿助手V1功能PRD.md)
   - 只定义 V1 的页面、交互、上下文、安全、错误处理、测试和验收标准。
   - V1 实施讨论和任务拆分以此文档为准。

3. [AI育儿助手V2第一阶段PRD](AI育儿助手V2第一阶段PRD.md)
   - 定义助手页集中快捷分析、会话上下文条和上下文生命周期。
   - 不包含 Room 历史会话、云同步或知识库。

后续阶段应分别建立独立 PRD，不直接把总体规划中的未来能力加入当前开发范围。
