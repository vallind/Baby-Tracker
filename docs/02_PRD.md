# 产品需求文档

## 1. 产品定位

面向 0-6 岁儿童家庭的成长记录与健康管理工具。帮助家长记录喂养、睡眠、生长数据，管理疫苗和健康档案，并通过统计分析了解宝宝的成长趋势。

## 2. 用户角色

| 角色 | 年龄 | 核心需求 |
|------|------|---------|
| 宝妈 | 22-40 | 记录日常育儿数据、查看成长情况、获取提醒 |
| 宝爸 | 22-45 | 共享数据、查看统计分析、接收通知 |
| 祖辈照护者 | 50-70 | 简单记录、查看提醒、操作方便 |

## 3. 功能列表

### V1.0 (当前范围)

| 模块 | 功能 | 优先级 |
|------|------|--------|
| 首页 | 宝宝信息卡片、功能导航、今日概览 | P0 |
| 喂养记录 | 母乳/配方奶/辅食/饮水 CRUD | P0 |
| 睡眠记录 | 夜间/小睡 CRUD，时长统计 | P0 |
| 生长记录 | 身高/体重/头围 CRUD，Vico 趋势图 | P0 |
| 疫苗接种 | 疫苗登记、状态跟踪、完成标记 | P1 |
| 健康档案 | 过敏史、既往病史、医生备注 | P1 |
| 提醒中心 | WorkManager 每日检查疫苗提醒 | P1 |
| 统计分析 | 喂养/睡眠/生长趋势图表 | P1 |
| 宝宝信息 | 姓名/性别/出生日期/出生数据 | P0 |
| 设置 | 主题切换、通知开关 | P2 |
| 关于 | 版本信息 | P2 |

### V1.5 (规划)

- 多宝宝支持
- 家庭共享
- 云同步

### V2.0 (规划)

- 医生协同
- 成长报告导出 (PDF/Excel)
- AI 成长分析与智能建议

## 4. 页面清单 (14页)

1. 首页 — 宝宝卡片 + 功能宫格 + 今日概览
2. 喂养记录 — 列表 + 删除
3. 新增喂养 — 类型/用量/备注
4. 睡眠记录 — 列表 + 删除
5. 新增睡眠 — 时间/类型
6. 生长记录 — 图表 + 列表
7. 新增生长 — 身高/体重/头围
8. 疫苗接种 — 列表 + 状态
9. 新增疫苗 — 名称/针次
10. 健康档案 — 表单编辑
11. 统计分析 — 汇总卡片 + 图表
12. 设置 — 主题/通知
13. 关于 — 版本信息
14. 宝宝信息 — 基础信息（首页内嵌）

## 5. 非功能需求

- 离线可用，纯本地存储
- 启动速度 < 2s
- 数据库查询 < 100ms
- 适配 API 24+ (Android 7.0+)
- 支持深色模式
