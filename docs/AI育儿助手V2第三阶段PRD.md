# Baby Tracker「AI 育儿助手」V2 第三阶段 PRD

> 文档状态：已实现
> 文档版本：0.1
> 更新日期：2026-07-24
> 阶段范围：本地会话历史

## 1. 阶段目标

让用户可以在 AI 助手页查看当前宝宝的历史对话、继续追问、搜索和删除，同时保证不同家庭和宝宝之间严格隔离。

## 2. 用户流程

```text
进入 AI 助手
  → 点击顶部“对话历史”
  → 搜索或选择一条历史
  → 加载完整问答并继续追问

或

进入对话历史
  → 开始新对话 / 删除指定对话
```

## 3. 实现范围

- AI 助手顶部增加历史入口，不修改其他业务页面和底部导航。
- 历史面板支持标题与回答预览搜索。
- 历史只展示当前家庭、当前宝宝的会话。
- 加载历史后继续发送的消息写回同一会话。
- 新对话不会删除已保存历史。
- 删除会话时级联删除该会话的本地消息。
- 保存最终回答、已停止的部分回答、思考内容、模型信息、引用范围和安全状态。
- 思考内容只用于历史展示，不进入下一轮模型上下文。

## 4. 数据库迁移

Room 数据库从 7 升级到 8：

- `ai_conversations`
  - `family_id`
  - `baby_id`
  - `title`
  - `created_at`
  - `updated_at`
- `ai_messages`
  - `conversation_id`
  - `role`
  - `content`
  - `reasoning_content`
  - 模型、引用、安全状态、消息顺序与时间

迁移只新增表和索引，不修改现有业务表，不清除已有宝宝及记录。

## 5. 隔离与隐私

- 所有列表、加载、更新和删除操作同时校验 `family_id` 与 `baby_id`。
- `ai_messages` 只能通过已经完成作用域校验的会话读取。
- AI 表不加入 `SyncEngine`、`sync_metadata`、Realtime 或 Supabase。
- 历史默认仅保存在当前设备，不向家庭成员共享。
- 删除宝宝时通过 Room 外键级联删除对应 AI 会话。

## 6. 页面状态

- 无历史：显示“还没有保存的对话”。
- 搜索无结果：显示“没有找到匹配的对话”。
- 当前会话：历史卡片使用选中态颜色。
- 切换家庭、宝宝或账号：取消当前请求并清空正在展示的会话。
- 数据库读写失败：记录错误日志，不阻断模型正常回答。

## 7. 验收标准

1. 首次有效提问后创建本地会话。
2. 最终回答完成后保存完整问答。
3. 重新打开历史后可以继续对话。
4. 搜索可以匹配标题和回答预览。
5. 删除会话后对应消息同时删除。
6. 不显示其他家庭或其他宝宝的历史。
7. 新增表不进入现有同步流程。
8. Room 7→8 迁移、Kotlin 编译及相关单元测试通过。

## 8. 不实现

- 不同步或共享 AI 会话。
- 不保存模型 API Key、用户 Token 或内部认证信息。
- 不增加收藏、导出、改名和批量删除。
- 不实现知识库、云端历史或 AI 分析缓存。
- 不在睡眠、喂养、健康和统计页增加入口。

## 9. 回滚说明

应用数据库升级到 8 后不能直接安装仍使用数据库 7 的旧版本。代码回滚时必须保留版本 8 的实体与迁移，或提供显式降级迁移，禁止使用破坏性迁移清空用户数据。
